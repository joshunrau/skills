# skills

My personal collection of [agent skills](https://skills.sh), installable with the skills CLI.

## Installation

Install all skills from this repo:

```sh
npx skills add joshunrau/skills
```

Or install a single skill:

```sh
npx skills add joshunrau/skills --skill interview
```

## Requirements

The skills assume the you have specified the following in `AGENTS.md`:

```md
## Reference Files

- `CODING_GUIDELINES.md`: the coding guidelines
- `SPEC.md`: the product specification.
- `docs/plans`: the plans directory
```
