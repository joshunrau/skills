# Hello World

A dummy skill used to verify that skills from this repository install and activate correctly.

## When to Use

- The user asks to test whether skills are working
- The user explicitly invokes the hello-world skill

## Steps

1. Greet the user with: "Hello from the joshunrau/skills repository! 🎉"
2. Confirm that the skill was loaded successfully.
3. If the user was testing their skills setup, let them know everything is working as expected.
